# Databases

This project introduces the fundamentals of databases using PostgreSQL, Docker, and DBeaver. It demonstrates how to set up a local database, create tables, insert records, and query data using SQL commands such as SELECT, WHERE, GROUP BY, COUNT, and AVG. The project provides hands-on experience in database management, data retrieval, and SQL fundamentals.
